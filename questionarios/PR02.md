## 12 · Múltipla escolha · C5 Classes, atributos de instância e construtor · com código

O que o programa imprime, e por quê?

```python
class Playlist:
    musicas = []

    def __init__(self, nome):
        self.nome = nome

    def adicionar(self, musica):
        self.musicas.append(musica)

rock = Playlist('Rock')
mpb = Playlist('MPB')
rock.adicionar('Smells Like Teen Spirit')

print(len(mpb.musicas))
```

- **A)** `1`, porque `musicas` foi declarada no corpo da classe e as duas playlists
  compartilham a mesma lista; para cada objeto ter a sua, ela precisa ser criada dentro do
  `__init__`.
- **B)** `0`, porque cada objeto criado recebe a sua própria lista vazia.
- **C)** `AttributeError`, porque `mpb` nunca chamou `adicionar` e por isso não tem o
  atributo `musicas`.
- **D)** `1`, porque `append()` sempre grava na classe, mesmo quando a lista é criada dentro
  do `__init__`.

**Gabarito: A.**
**B** supõe o atributo de classe copiado para cada instância; **C** confunde chamar o método
com criar o atributo; **D** acerta o número por um motivo falso — com a lista no `__init__`,
a saída seria `0`.

## 15 · Múltipla escolha · C6 Encapsulamento com property e métodos de classe e estáticos · com código

Qual é a saída do programa?

```python
class Restaurante:
    def __init__(self, nome, nota):
        self.nome = nome
        self._nota = nota

    @property
    def nota(self):
        return f'{self._nota:.1f}'

bistro = Restaurante('Bistrô', 9)
print(bistro.nota())
```

- **A)** `TypeError: 'str' object is not callable` — `nota` é uma property, lida como
  atributo: o certo é `bistro.nota`, sem parênteses.
- **B)** `9.0`
- **C)** O endereço do método em memória, algo como `<bound method Restaurante.nota>`.
- **D)** `AttributeError`, porque o underscore em `_nota` impede a leitura do valor fora da
  classe.

**Gabarito: A.** A property devolve a string `'9.0'`; os parênteses tentam chamá-la como
função.
**B** ignora os parênteses; **C** trata a property como método não chamado; **D** supõe que o
underscore é uma trava da linguagem.

## 16 · Múltipla escolha · C6 Encapsulamento com property e métodos de classe e estáticos

Em `self._nota`, o que o underscore indica — e quem valida o valor quando a nota é alterada
de fora da classe?

- **A)** É convenção: sinaliza que o atributo é de uso interno, sem a linguagem bloquear o

- **B)** O underscore torna o atributo inacessível fora da classe; a validação fica no

**Gabarito: A.** **B** confunde convenção com proteção da linguagem; **C** troca atributo de

## 17 · Múltipla escolha · C7 Herança, polimorfismo e classes abstratas · com código

Qual é a saída do programa?

```python
class Midia:
    def __init__(self, titulo, ano):
        self.titulo = titulo
        self.ano = ano

class Filme(Midia):
    def __init__(self, titulo, ano, duracao):
        self.duracao = duracao

interestelar = Filme('Interestelar', 2014, 169)
print(interestelar.titulo)
```

- **A)** `AttributeError: 'Filme' object has no attribute 'titulo'`, porque `Filme`
  sobrescreveu o construtor e não chamou `super().__init__(titulo, ano)`.
- **B)** `Interestelar`, porque a herança copia os atributos da superclasse automaticamente.
- **C)** `None`, porque o atributo herdado existe, mas chega sem valor.
- **D)** Um erro de sintaxe: uma subclasse não pode ter `__init__` próprio, só métodos novos.

**Gabarito: A.** Herdar dá acesso ao construtor da superclasse, mas não o executa.
**B** e **C** supõem atributos herdados automaticamente; **D** nega a sobrescrita do
construtor.

## 18 · Dissertativa · C7 Herança, polimorfismo e classes abstratas

No sistema de restaurantes existem `Prato` e `Bebida`, e agora é preciso representar um
**combo**, que junta um prato e uma bebida com preço fechado. Diga se o combo deve **herdar**
de `Prato` ou **conter** um prato e uma bebida, e justifique.

**O que a resposta precisa conter:**

1. A escolha de **composição** (conter), com a justificativa certa: um combo não *é* um
   prato, ele *tem* um prato e uma bebida (ponto principal).
2. O critério usado para decidir — herança quando a subclasse é um tipo do que herda
   ("é um"), composição quando ela é formada por outras partes ("tem um").
3. Uma consequência prática de errar a escolha: herdando de `Prato`, o combo carregaria
   atributos e métodos que não fazem sentido para ele, e não teria onde guardar a bebida.

**Faixas:** os três pontos = integral · escolhe composição e dá só o critério "é um / tem
um", sem consequência = parcial · escolhe herança, ou escolhe composição sem justificar =
nulo.
