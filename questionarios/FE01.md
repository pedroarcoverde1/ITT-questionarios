## 1 · Múltipla escolha · C1 Como a internet e a web funcionam

Você digita o endereço do site da escola e aperta Enter. Qual descrição do que acontece está
correta?

- **A)** O navegador (cliente) pergunta ao DNS qual é o endereço numérico do servidor; com
  ele, pede os arquivos da página a esse servidor, que responde enviando-os.
- **B)** O DNS é o servidor onde o site está guardado, e o navegador baixa a página direto
  dele.
- **C)** O site inteiro já está salvo no navegador; digitar o endereço apenas abre a cópia
  local.
- **D)** O Wi-Fi é a internet: é ele que guarda os sites e entrega a página ao navegador.

**Gabarito: A.** **B** confunde o DNS (a lista telefônica) com o servidor (quem hospeda);
**C** supõe o site salvo localmente; **D** confunde a forma de conexão com a rede.

## 2 · Dissertativa · C1 Como a internet e a web funcionam

Descreva, em passos, o caminho entre digitar o endereço de um site e a página aparecer na
tela. Diga também se internet e web são a mesma coisa.

**O que a resposta precisa conter:**

1. Que o nome digitado é traduzido em um endereço numérico pelo DNS (ponto principal).
2. Que o navegador, como **cliente**, faz um pedido ao **servidor**, que responde enviando os
   arquivos da página — HTML, CSS, imagens.
3. Que o navegador monta e desenha a página a partir desses arquivos.
4. Que internet e web não são a mesma coisa: a internet é a rede que liga os computadores, e
   a web é um dos serviços que funcionam sobre ela.

**Faixas:** pontos 1 a 3 mais a distinção = integral · descreve cliente e servidor mas não
menciona o DNS, ou erra a distinção = parcial · só "a página é baixada da internet" = nulo.

## 3 · Múltipla escolha · C2 HTML semântico · com código

Quais **duas** correções tornam este trecho semântico e com a hierarquia de títulos correta?

```html
<div class="topo">
  <h1>Blog da Escola</h1>
</div>
<div>
  <a href="#noticias">Notícias</a>
  <a href="#eventos">Eventos</a>
</div>
<div>
  <h3>Feira de ciências</h3>
  <p>A feira acontece em novembro.</p>
</div>
```

- **A)** Trocar as `div` por `header`, `nav` e `main` (com um `article` para a notícia), e
  usar `h2` no título da notícia em vez de pular de `h1` para `h3`.
- **B)** Manter as `div` e acrescentar classes descritivas, e trocar o `h3` por `h1`, para que
  o título da notícia tenha o mesmo peso do título do site.
- **C)** Trocar as três `div` por `section` e escolher o nível do título pelo tamanho que se
  quer na tela.
- **D)** Trocar as `div` por `span`, que é a tag semântica para blocos, e deixar o `h3` como
  está.

**Gabarito: A.** **B** mantém a `div` para tudo e cria dois `h1`; **C** usa `section` onde
cabem tags mais precisas e escolhe título por tamanho; **D** troca um elemento de bloco por um
de linha.

## 4 · Múltipla escolha · C2 HTML semântico

Na página de um evento há três blocos: o menu de navegação do topo, a programação do dia e um
rodapé com os contatos. Quais tags usar?

- **A)** `<nav>` para o menu, `<main>` com `<section>` para a programação e `<footer>` para os
  contatos.
- **B)** `<div>` nos três, diferenciando por classe, porque as tags semânticas só mudam a
  aparência.
- **C)** `<header>` para o menu, `<article>` para o rodapé e `<aside>` para a programação.
- **D)** `<nav>` para o menu, `<footer>` para a programação (que fica no fim da página) e
  `<main>` para os contatos.

**Gabarito: A.** **B** ignora que a semântica informa navegadores e leitores de tela; **C** e
**D** escolhem a tag pela posição na tela, não pelo papel do conteúdo.

## 5 · Múltipla escolha · C2 HTML semântico

Em um blog, o `<h1>` é o nome do site e cada notícia começa com `<h3>` "porque o `h2` ficava
grande demais". Qual avaliação está correta?

- **A)** O nível do título indica a hierarquia do conteúdo, não o tamanho: as notícias devem

- **B)** Está correto: o nível do título é escolhido pelo tamanho que se quer na tela.
- **C)** Está correto, desde que exista pelo menos um `h2` em algum outro lugar da página.
- **D)** O certo seria usar `h1` em cada notícia, para que todas tenham o mesmo peso do nome

**Gabarito: A.** Pular níveis desorganiza a leitura por leitores de tela e por mecanismos de
busca.
**B** e **C** mantêm a escolha pelo visual; **D** cria vários `h1` e apaga a hierarquia.

## 6 · Múltipla escolha · C2 HTML semântico

O que o atributo `alt` de uma imagem faz, e quando ele é necessário?

- **A)** Descreve o conteúdo da imagem para quem não a vê — leitor de tela, ou quando a
  imagem não carrega. Toda `<img>` precisa dele; em imagem puramente decorativa ele fica
  vazio (`alt=""`).
- **B)** Define o texto que aparece embaixo da imagem na página.
- **C)** Só é necessário quando a imagem é um link.
- **D)** Serve para melhorar o SEO, repetindo nele as palavras-chave da página.

**Gabarito: A.** **B** confunde `alt` com legenda (`figcaption`); **C** restringe o requisito;
**D** é a prática de repetir palavra-chave, que não ajuda e piora a leitura.

## 7 · Múltipla escolha · C3 Seletores e propriedades CSS · com código

Com esse HTML e esse CSS, qual cor fica cada item da lista?

```html
<ul class="menu">
  <li class="item destaque">Início</li>
  <li class="item">Cardápio</li>
  <li id="contato" class="item">Contato</li>
</ul>
```

```css
.item { color: gray; }
#contato { color: green; }
.destaque { color: orange; }
```

- **A)** Início laranja, Cardápio cinza, Contato verde.
- **B)** Início cinza, Cardápio cinza, Contato verde, porque a primeira regra do arquivo
  vence para "Início".
- **C)** Início laranja, Cardápio cinza, Contato cinza, porque `#contato` deveria ter sido
  escrito `.contato`.
- **D)** Todos laranja, porque a última regra do arquivo sempre vence sobre as anteriores.

**Gabarito: A.** `.item` e `.destaque` têm a mesma especificidade, e entre iguais vence a
última declarada — daí "Início" laranja. `#contato` é um id e vence qualquer classe.
**B** inverte o critério de empate; **C** confunde `#` com `.`; **D** aplica a última regra a
elementos que o seletor não alcança.

## 8 · Múltipla escolha · C3 Seletores e propriedades CSS · com código

De que cor fica o parágrafo?

```html
<p class="aviso" id="principal">Entrada gratuita até as 20h.</p>
```

```css
p          { color: black; }
.aviso     { color: red; }
#principal { color: blue; }
p.aviso    { color: green; }
```

- **A)** Azul, porque o seletor de **id** tem a maior especificidade das quatro regras.
- **B)** Verde, porque `p.aviso` é a última regra do arquivo.
- **C)** Vermelho, porque uma classe sempre vence seletor de elemento e de id.
- **D)** Preto, porque o seletor de elemento é o mais específico de todos.

**Gabarito: A.** Id vence classe, que vence elemento; a ordem no arquivo só decide empates.
**B** supõe que a última regra sempre vence; **C** e **D** invertem a escala de
especificidade.

## 10 · Múltipla escolha · C3 Seletores e propriedades CSS

A regra `.card { width: 300; margin-top: 16px; }` não aplica a largura esperada. Por quê?

- **A)** Falta a unidade: `width` precisa de um valor com unidade, como `300px` ou `30rem` —
  sem ela a declaração é inválida e o navegador a ignora.
- **B)** `width` não aceita valor em pixels, só em porcentagem.
- **C)** A regra está correta; o problema é que `margin-top` cancela a largura declarada.
- **D)** Falta repetir a unidade no seletor, escrevendo `.card-px`.

**Gabarito: A.** Uma declaração inválida é descartada, e só ela — o `margin-top` continua
valendo.
**B** inventa uma restrição; **C** confunde espaçamento com largura; **D** não existe.

## 11 · Múltipla escolha · C4 Box model e organização do código · com código

Quanto espaço horizontal o `.card` ocupa, e o que mudaria com `box-sizing: border-box`?

```css
.card {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

- **A)** 250px; com `box-sizing: border-box`, o total passaria a 200px, porque padding e
  borda entrariam **dentro** da largura declarada.
- **B)** 200px; padding e borda já ficam por dentro por padrão, e `border-box` não mudaria
  nada.
- **C)** 245px, porque a borda não entra na conta da largura.
- **D)** 250px; com `border-box` o total passaria a 300px, porque a propriedade soma a borda
  dos dois lados outra vez.

**Gabarito: A.** No padrão `content-box`, 200 + 20×2 + 5×2 = 250px.
**B** descreve o comportamento do `border-box` como se fosse o padrão; **C** esquece um dos
lados da borda; **D** inverte o efeito da propriedade.

Num cartão de prato, o texto está encostado na borda interna do cartão, e os cartões estão

## 16 · Dissertativa · C6 Acessibilidade digital e SEO técnico

Explique por que o texto alternativo de uma imagem importa e a quem ele atende. Depois,
comente a afirmação: "acessibilidade é coisa para pessoas cegas".

**O que a resposta precisa conter:**

1. Que o `alt` descreve o conteúdo da imagem para quem não pode vê-la, de modo que a
   informação não se perca (ponto principal).
2. Quem é atendido: pessoas que usam leitor de tela, e também qualquer pessoa cuja imagem não
   carregou — conexão ruim, erro no caminho do arquivo.
3. Que a afirmação é falsa, com pelo menos um outro público citado: baixa visão, daltonismo,
   deficiência motora que impede o uso do mouse, deficiência cognitiva, ou limitação
   situacional (tela no sol, uma mão ocupada).

**Faixas:** os três pontos = integral · pontos 1 e 2, sem ampliar o público = parcial ·
só "é bom para acessibilidade" sem dizer a quem serve = nulo.

## 17 · Múltipla escolha · C7 Layouts com Flexbox e CSS Grid · com código

Qual é o resultado visual na barra do topo?

```html
<div class="barra">
  <img src="logo.png" alt="Logo do evento">
```

```css
.barra {
```

## 19 · Múltipla escolha · C8 Responsividade com mobile first e media queries · com código

Em uma tela de **800px** de largura, qual tamanho de fonte o `body` recebe?

```css
body { font-size: 16px; }

@media (min-width: 768px) {
  body { font-size: 18px; }
}

@media (min-width: 1200px) {
  body { font-size: 20px; }
}
```

- **A)** 18px — a regra de `min-width: 768px` se aplica; a de 1200px não, porque a tela é
  menor que isso.
- **B)** 16px — nenhuma media query se aplica, porque `min-width` vale para telas **menores**
  que o valor informado.
- **C)** 20px — a última media query do arquivo sempre vence as anteriores.
- **D)** 16px — a regra escrita fora das media queries é a mais específica e vence todas.

**Gabarito: A.** `min-width: 768px` significa "desta largura **para cima**".
**B** inverte o sentido de `min-width`; **C** ignora a condição da media query; **D** confunde
ordem com especificidade.

## 20 · Múltipla resposta · C8 Responsividade com mobile first e media queries

Quais práticas seguem de fato o princípio mobile first? (marque todas)

- **A)** Escrever o estilo base pensando na tela pequena e acrescentar ajustes com
  `min-width` para telas maiores.
- **B)** Usar unidades relativas (`%`, `rem`, `vw`) em vez de larguras fixas em px onde o
  layout precisa adaptar.
- **C)** Incluir a meta tag `viewport` no `<head>` da página.
- **D)** Criar um breakpoint para cada aparelho popular do mercado.
- **E)** Escrever o estilo base para o desktop e usar `min-width` para corrigir o celular
  depois.

**Gabarito: A, B e C.**
**D** cria breakpoints por aparelho em vez de por conteúdo, e a lista nunca termina; **E**
inverte o mobile first — e `min-width` não alcança telas menores que o breakpoint.
