AVALIAÇÃO PÓS-TRILHA — PYTHON COM ORIENTAÇÃO A OBJETOS

Contexto: questionário aplicado depois de a trilha ser concluída, em uma ONG que ensina
computação para adolescentes do ensino fundamental II e médio. O estudante já passou por

ASSUNTOS

C1 - Programa Python, variáveis e strings
  Cobrar: prever a saída de um trecho com variáveis e print(); montar uma f-string que
  interpola o valor de uma variável; reconhecer que input() devolve string e precisa de
  conversão para cálculo numérico.
  Erros típicos, para virar alternativa errada: somar o retorno de input() como se fosse
  número; confundir = com ==; esquecer o f no início da f-string; errar a indentação

C2 - Condicionais, laços e tratamento de exceções
  Cobrar: escolher entre for e while justificando pela condição de parada; prever quantas
  vezes um laço executa; identificar qual except captura um erro específico (ValueError,
  KeyError).
  Erros típicos: condição de parada que gera laço infinito; erro de 1 na contagem de
  range(), esquecendo que o fim é exclusivo; except genérico que esconde o erro real;
  código dependente do laço escrito fora da indentação dele.

C3 - Listas e dicionários
  Cobrar: justificar dicionário quando o dado tem rótulo e lista quando a ordem importa;
  acessar um valor aninhado em uma lista de dicionários; prever o resultado de append(),
  len() e de um for sobre a coleção.
  Erros típicos: achar que a lista começa no índice 1; acessar chave inexistente sem
  tratar KeyError; confundir a sintaxe de lista [] com a de dicionário {}; modificar a
  lista enquanto a percorre.

C4 - Funções e módulos
  Cobrar: distinguir parâmetro de argumento e return de print; identificar qual trecho
  repetido deveria virar função; escrever o import correto para usar uma classe ou função
  de outro arquivo.
  Erros típicos: usar print() no lugar de return e depois tentar aproveitar o valor;
  definir a função e esquecer de chamá-la; confundir variável local com global.

C5 - Classes, atributos de instância e construtor
  Cobrar: dado "um jogo tem nome, nota e gênero", escrever a classe com __init__ e os três
  atributos; explicar o papel do self no construtor e nos métodos; distinguir a classe
  (o molde) do objeto (a instância).
  Erros típicos: esquecer o self na assinatura do método; confundir atributo de classe com
  atributo de instância; chamar __init__ diretamente em vez de instanciar a classe; achar
  que todos os objetos compartilham os mesmos valores de atributo.

C6 - Encapsulamento com property e métodos de classe e estáticos
  Cobrar: reconhecer que @property permite rodar lógica (validação, formatação) ao ler um
  atributo; identificar a convenção do underscore (_atributo) como sinal de uso interno;
  saber que é o setter quem valida o valor antes de atribuir.
  Erros típicos: chamar a property com parênteses, como se fosse método; criar um setter
  com nome diferente do getter; achar que o underscore impede o acesso pela linguagem.

C7 - Herança, polimorfismo e classes abstratas
  Cobrar: dado um conjunto de classes, apontar qual deveria ser a superclasse e por quê;
  prever qual implementação de método roda em uma chamada polimórfica; explicar por que
  uma classe abstrata não pode ser instanciada.
  Erros típicos: esquecer super().__init__() na subclasse e perder os atributos herdados;
  confundir sobrescrever um método com criar outro de nome parecido; usar herança onde
  composição seria mais adequada.

C8 - Ambiente virtual, arquivos JSON e consumo de API
  Cobrar: explicar para que serve um ambiente virtual em uma frase; acessar um campo
  aninhado de um JSON de resposta em Python; reconhecer o significado dos status 200 e 404.
  Erros típicos: instalar a dependência sem ativar o ambiente virtual; tratar a resposta
  da API como texto quando precisa de .json(); confundir o arquivo JSON com um dicionário
  Python já pronto.
